# Yangilanish
- Tovuq qanotchalari shashlik: 18 000 so‘m / dona, UZ/RU/EN, yuborilgan rasm.
- Bosh sahifa yuqorisida manzil va Google Maps tugmasi; telefonda menyuni ochmasdan ko‘rinadi.

## Ishga tushirish
package.json turgan papkada npm install, keyin npm run dev.
Eski .env faylingizni va .git papkangizni saqlang.

## Jonli menyuga qo‘shish
Frontendni GitHub orqali Netlifyga joylang. Keyin TOVUQ_QANOTCHALARI.sql faylidagi so‘rovni mavjud Supabase loyihangizning SQL Editor oynasida bajaring. Bu yangi taomni admin panel va jonli menyuga qo‘shadi. Bir xil id mavjud bo‘lsa o‘zgartirmaydi. Backendni yangilash shart emas.
