# Yangilash
1. ZIPni oching. Yangi fayllarni mavjud frontendga ko‘chiring; .git va .env fayllaringizni saqlang.
2. npm install va npm run build buyrug‘ini bajaring. Keyin GitHubga push qiling va Netlify deploy tugashini kuting.
3. SAYT_YANGILASH.sql faylidagi kodni mavjud Supabase loyihangizning SQL Editor oynasida bajaring. Bu bazadagi choyxona nomi, sho‘rva narxi (40 000 so‘m / kosa) va menyu tavsiflarini yangilaydi. Boshqa narxlar o‘zgarmaydi. Backendni qayta deploy qilish kerak emas.

Video ko‘rinishi: metadata yuklanadi, videoning dastlabki soniyasidagi kadr chiqariladi. Avtomatik ijro yo‘q. Yuklashda kutish kartasi, xatoda tushunarli yozuv chiqadi. Sana-vaqtlar Toshkent vaqti bilan dd.mm.yyyy, hh:mm shaklida.

Saqlangan video uchun alohida muqova fayli bazaga yuklanmaydi; kadr brauzerda ko‘rsatiladi. Haqiqiy Storage video ijrosi va mobil ko‘rinishni deploydan keyin tekshiring.
